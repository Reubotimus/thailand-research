# Per-activity research

One JSON file per activity, named `<id>.json`, following `Research` in `data/types.ts`.
Research must use live web sources. Prefer official sources for prices, hours, bookings and dated events.
Record unknowns explicitly; do not turn report claims into verified facts.
Images must depict the actual activity or an explicitly described representative example. Include direct image URL, source page, descriptive alt text, credit and known reuse terms (or `Permission not established; linked reference`). Never invent URLs or imply a license without evidence. Prefer Wikimedia Commons or other reusable imagery. Two complementary photos where practical; one good photo sufficient when obscure.
Use 2026-10-17 as the planning date but record actual research date from environment. Flag stale event years. No bookings or messages to venues.
